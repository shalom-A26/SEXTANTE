# Taxonomía ESCO

Descarga el paquete oficial **ESCO v1.2.1, clasificación, CSV, español** desde
<https://esco.ec.europa.eu/es/use-esco/download> y extrae aquí su contenido.

El procesamiento busca `skills_es*.csv`, registra la versión usada y no incluye
estos archivos externos en Git. No reemplaces el catálogo con listas manuales.
